# Dataset

## RAVDESS Speech 16K

This project uses the 16 kHz version of the RAVDESS
(Ryerson Audio-Visual Database of Emotional Speech and Song)
dataset for speech emotion recognition.

### Download

Official dataset:

https://zenodo.org/records/11063852

Download:

Audio_Speech_Actors_01-24_16k.zip

### Dataset Details

- 24 actors
- 12 male and 12 female actors
- 1,440 speech audio files
- 8 emotion classes
- WAV audio format
- 16 kHz sampling rate

### Emotion Classes

01 - Neutral
02 - Calm
03 - Happy
04 - Sad
05 - Angry
06 - Fearful
07 - Disgust
08 - Surprised

### Dataset Placement

After downloading and extracting the dataset, place it as:

data/
└── Audio_Speech_Actors_01-24_16k/
    ├── Actor_01/
    ├── Actor_02/
    ├── ...
    └── Actor_24/
